# Progress Steps

Project #02 of my **50 Days 50 Projects** challenge.

A simple progress step component with Prev/Next buttons. The active steps and progress bar update as you move through the steps.

## Built With

- HTML
- CSS
- JavaScript

## What I Learned

- `querySelectorAll()` and `forEach()`
- Managing UI state with `currentActive`
- Adding/removing classes with `classList`
- Handling click events
- Updating styles with JavaScript
- Disabling buttons at the beginning/end
- CSS pseudo-elements and transitions
