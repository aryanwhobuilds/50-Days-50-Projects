# Blurry Loading

A simple loading screen where the background starts blurred and gradually becomes clear as the loading percentage reaches 100%.

Built this to practice JavaScript intervals, DOM manipulation, opacity changes, and mapping values between ranges.

## What I Practiced

- `setInterval()` and `clearInterval()`
- DOM manipulation
- Changing styles with JavaScript
- Opacity transitions
- Mapping values from one range to another
