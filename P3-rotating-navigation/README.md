# Rotating Navigation Animation

A small UI project where the main page rotates to reveal a hidden navigation menu.

Built this to practice CSS transforms, transitions, positioning, and JavaScript class toggling.

## What I Practiced

- CSS `transform` and `transition`
- Rotating elements with `rotate()`
- Positioning and layout
- JavaScript event listeners
- Toggling classes with `classList`
